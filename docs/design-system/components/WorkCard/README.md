# WorkCard

Card de Selected work, como en el wireframe: bloque de media a ancho completo y, debajo, una fila con índice y título a la izquierda, y tags y año a la derecha.

- Se apilan a ancho completo, una por proyecto, con 56px entre ellas; cada una abre un popup de case study.
- Media con `radius-lg`, imagen o video, de unos 420px de alto en un ancho de 1344px. Sin velo encima. En hover puede reproducir un preview en video.
- Índice (`01`) en `ink-muted`, título en `h3`, tags con el estilo Tag por defecto (máximo 3) y año en `ink-muted`.
- La fila pasa a dos líneas cuando no cabe en el ancho.
- El consumidor aporta imagen o video (con `alt` o poster), título, tags y año.
