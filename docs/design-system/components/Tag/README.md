# Tag

Etiqueta compacta en Jokker para stack, estado y metadata.

- **Por defecto:** texto `white`, fondo `tag-bg` (#333), `border-radius` 1.55em, padding .25em .65em, Jokker `font-size` 1.2em, `line-height` 1.15, `letter-spacing` −0.02em. Es igual en los dos temas (12.6:1).
- **accent:** fondo `accent`, texto `on-accent`. Para estados como "Disponible"; pocos por pantalla.
- **alt:** fondo `accent-alt`, texto `on-accent-alt`.
- **Sticker:** el tag por defecto con una rotación de unos −6° a 6°, solo en el hero alrededor del H1.
- Las medidas en em dependen de la base de 14px de la página: el tag mide 16.8px de texto.
- El consumidor aporta el texto. Los tags de cards no pasan de 3.
